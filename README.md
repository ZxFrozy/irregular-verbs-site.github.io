# Irregular Verbs — тренажёр

## Как запустить на GitHub Pages

1. Создай новый репозиторий на GitHub (например, `irregular-verbs-quiz`).
2. Загрузи в репозиторий файл `index.html` из этой папки.
3. Открой **Settings → Pages**.
4. В разделе **Build and deployment** выбери **Deploy from a branch**.
5. Выбери ветку `main`, папку `/(root)` и нажми **Save**.
6. Через минуту сайт будет доступен по адресу вида `https://ТВОЙ-ЛОГИН.github.io/irregular-verbs-quiz/`.

## Возможности
- 56 глаголов из списка на фото, по одному вопросу за раз
- несколько русских значений для каждого глагола
- проверка трёх форм
- случайный порядок, счёт и серия правильных ответов
- отдельное повторение ошибок и новые круги
- прогресс раунда хранится локально в браузере

Это статический сайт: сервер и платный хостинг не нужны.
